# Environment setup for Ubuntu
This repository houses an Ansible playbook and configurations for setting up a Linux environment geared towards development in a shell. It was originally designed around an Ubuntu/Debian-based AMD64 machine using a bash shell, but has since been updated for ARM64 as well.

## Prerequisites
A Nerd Font should be installed and enabled in the terminal to properly display the glyphs in the command prompt.

## Usage
Clone this repository and run `setup.sh`.

## Notes
`vim/plugin/clip.vim` is a vim command for WSL2 distributions that allows copying text selected in Visual mode to the clipboard of the Windows machine. It can be omitted for non-WSL2 enviroments.
